# Sprint 19-A Provider 引导与企业级操作反馈

## 已批准边界

- `AISearchProviderConfig` 继续作为 Provider 配置事实源。
- 环境变量引用保持向后兼容；新增直接粘贴密钥时使用 AES-256-GCM 服务端加密。
- 浏览器永不读取已保存明文，只接收掩码、状态和安全错误类别。
- `AutomationRun` / `AutomationStep` 仅作为执行审计层，不创建新的业务任务系统。
- 执行反馈必须来自真实请求状态或数据库状态，不模拟进度或成功结果。

## 交互结构

Provider 页面采用“引导总览 → 四个平台卡片 → 真实检测 → 历史结果”的顺序。每张卡片展示官方入口、安全说明、隐藏密钥输入、测试、保存和可恢复的测试结果。Automation 页面展示运行摘要、真实步骤、活动日志、默认折叠的技术详情以及明确的不可比较空状态。

## 安全与失败恢复

直接密钥仅在提交请求中短暂存在，服务端加密后落库；测试请求不会记录密钥。Provider 错误统一映射为用户可理解的类别，服务器日志只记录 Provider、分类代码和安全的技术代码。重复提交由禁用状态和数据库唯一约束共同防护。
